# 📒 Command-Line Contact Book (Python)

This is a simple Command-Line Contact Book application built using Python.
The project is part of Python Fundamentals learning.

## 🚀 Features
- Add new contacts
- View all contacts
- Search contacts by name
- Contacts are stored in a text file

## 🛠️ Technologies Used
- Python
- File Handling
- Command Line Interface (CLI)
